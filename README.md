# Столб — трекер реабилитации спины

**Сайт: https://gerol4lfun.github.io/stolb/** — открывай прямо по этой ссылке, добавь на главный экран iPhone (Safari → «Поделиться» → «На экран „Домой“»).

Личный трекер. Один HTML-файл + зашифрованный архив данных. Работает как сайт по ссылке, развёрнут на GitHub Pages.

## Как устроена приватность

- **`index.html`** (публичный) — сам трекер. В нём **нет ни одного твоего медданного**: ни имени, ни МРТ, ни анализов. Только механика столба, задачи, графики. Данные дня живут в памяти телефона (localStorage), на сервер не уходят.
- **`vault.json`** (публичный, но **зашифрован**) — сюда упакованы МРТ, лаборатория, заметки и все 28 PDF. Шифр AES-256-GCM, ключ из твоего пароля (PBKDF2, 250k итераций). Без пароля это нечитаемый мусор — даже если кто-то найдёт репозиторий или ссылку.
- **Пароль** ты задаёшь у себя на компьютере командой ниже. Он **никуда не сохраняется** и не попадает в репозиторий.
- Вкладка «Данные» просит пароль; расшифровка идёт **в браузере**. Красные флаги (безопасность) и экспорт доступны без пароля.
- Поисковики закрыты (`noindex` + `robots.txt`).

> ⚠️ Пароль восстановить нельзя. Забыл — просто пересобери архив заново (оригиналы анализов у тебя на компе). Данные при этом не теряются.

**Демо-режим (песочница):** https://gerol4lfun.github.io/stolb/?demo — открывает всё сразу (таблетки, курсы, столб) как в день 1, с кнопками листания дней вперёд. Реальная работа — по обычной ссылке без `?demo`, стартует 15.07 с чистого листа.

## Обновить данные или программу позже

- **Поменялись анализы/заметки:** отредактируй `plaintext/vault-source.json` (или замени PDF в `analyses/`) → `node tools/encrypt.mjs` → `git add vault.json && git commit -m "update" && git push`.
- **Сменить пароль:** просто перезапусти `node tools/encrypt.mjs` с новым паролем → закоммить `vault.json` → `git push`.
- **Программа тренировок** редактируется прямо в приложении (вкладка «Программа»), пуша не требует.

## Что уходит в репозиторий, а что нет

Уходит: `index.html`, `vault.json` (шифр), `robots.txt`, `README.md`, `tools/`.
**Не уходит никогда** (защищено `.gitignore`): `plaintext/` (медданные в открытом виде) и `analyses/` (оригиналы PDF). Держи эти папки у себя локально — они нужны только для пересборки архива.

## Лекарства (ТЗ v2)

Расписание 7 препаратов зашито в код (`SLOTS` + `DEFAULT_COURSES` в index.html), назначено врачом 14.07.2026. Таблетки и прогулки сгруппированы по приёмам пищи на главном экране — один триггер «поел → выпил → вышел». Правила: в UI никаких миллиграммов (только штуки) и никаких советов/предупреждений — приложение только считает. Lyrica — степпер 0/1/2, попадает в экспорт и на график в «Динамике». День курса считается от даты старта (правится во вкладке «Программа»), пропуск день не сдвигает. Курс с остатком ≤3 дней даёт спокойную плашку; завершённый курс исчезает из «Сегодня» и уезжает в блок «Курс завершён». Таблетки не растят столб — он только от движения.

## Правила, зашитые в логику

- **Старт программы — 15 июля 2026.** До этой даты счётчик показывает «СТАРТ 15.07», день 1 наступает 15-го.
- День с любым движением добавляет позвонок. **Пропуск не обнуляет столб** — стрик-давление запрещено сознательно (ТЗ §7).
- «Записать день» с направлением «↓ ниже» или скачком боли в ноге ≥3 к среднему за 7 дней включает **красный светофор** на сегодня и завтра.
- Сутки считаются с 04:00 — запись в час ночи попадает в прошедший день.

## Синхронизация устройств

Вкладка «Данные» → «Синхронизация устройств». Работает через секретный GitHub Gist на аккаунте пользователя; содержимое шифруется (AES-256-GCM, ключ выводится из токена). Настройка: создать классический токен с единственным правом `gist` (github.com/settings/tokens) и вставить его в приложение на каждом устройстве — один раз. Слияние: каждый день выигрывает та версия, что менялась позже (`u`-метка); программа и курсы — по `metaU`. Пул при открытии/возврате фокуса, пуш с дебаунсом 2 с после изменений. В демо-режиме синхронизация отключена.

## Замер зоны боли

Вместо абстрактных «выше/ниже» — лесенка зон (упрощённая карта тела, как в PainScale/Manage My Pain): «до куда сегодня спускалась боль» — поясница/ягодица/бедро/голень/стопа. Направление (централизация/периферизация) приложение выводит само, сравнивая с прошлой записью; красный светофор срабатывает как раньше.

## Экспорт в чат

Вкладка «Данные» → «Экспорт данных в буфер» → вставить в чат реабилитации. Экспортируются только данные трекера (столб, боль) — без медкарты.
